# Native typography working source

These two scripts record the 4 November 2026 typography component changes. They do not generate media through a paid API and do not modify the delivered master.

- `refined_titles.py` extends the existing private `master_titles.py` renderer: larger qualified period cards and a Taswira map CTA, with the retained original cultural/production emblems and licensed typefaces.
- `render_refined_graphics.py` writes separate 1080×1920/24 fps silent opening/ending components. The final Arthur/OST mix is not part of these files.

They are **working component sources, not a standalone distribution**. The existing renderer classes, source videos, original supplied logos, font files/licences and local production paths are private inputs. No image, audio, font or model binary is included here. The prototype paths describe the production environment and must be adapted for another workstation.

See [native rebuild checkpoint](../NATIVE-REBUILD-PROGRESS-2026-11-04.md) for exact exported hashes, decoding/browser evidence and unresolved full-film quality. No component check is an approval of the mounted scene or a replacement delivery. The full controlled-motion scenes and rejected integration experiments are retained privately; their asset/source disclosures are in [the motion study record](../CONTROLLED-PROCESSION-PROOF-2026-11-04.md).
