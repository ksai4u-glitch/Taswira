## Cross-cutting findings

- **Kogi.** The only primary text read places "Kogi" as a division in Kwara in 1976. The 1991 creation (parents, date, decree) has **no primary source opened**. A search snippet in an earlier run named Kwara, Benue and possibly Niger as parents; that is not verified here.
- **Ebonyi.** Abia and Enugu are confirmed by the 1996 speech extract only. No decree.
- **FCT.** Not verified. In 1976 "Abuja" was inside Niger State (primary). The FCT decree and the 1991 move of the capital need sources.
- **Boundary adjustment.** Both 1967 (s.6) and 1976 (s.4) set up commissions to adjust boundaries by Supreme Military Council approval, and the 1996 speech defers adjustments to a later panel. So the schedules are **not** final lines. No adjusted boundary has been sourced.
- **Geometry.** The 1967 and 1976 schedules are by province, division and district. I did **not** compare them with modern ADM1 units, so I cannot say they never coincide. What the schedules show is that several areas are named below state level (Jarawa District, Uba District, Ndoni area, Opobo Division split, Kogi/Abuja divisions), so ADM1 building blocks are **likely to need LGA/division-level geometry** for those cases. This remains a hypothesis until compared.
- None of the five sources gives coordinates, so none supports drawing boundaries. Text schedules can support a table or a named-areas description.
